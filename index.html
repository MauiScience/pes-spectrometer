Binding-energy axis
Binding energies are simulated instructional values (MJ/mol), consistent with the electron configuration shown for each element (Cr and Cu reflect the standard 4s¹3d⁵ / 4s¹3d¹⁰ anomalies). Peak heights are set from electron configuration, so each spectrum's electron counts sum to the atomic number. The far-left core peaks span hundreds of MJ/mol while valence peaks sit near 0.5–1 — use the Log axis to see them all at once, or Linear for the true College Board spacing.
